This entry explains an escalator to a 10-year-old in exactly two lines: the first line pictures it as a staircase that swallowed a treadmill, carrying your feet upstairs while you just stand there, and the second line honestly says what that analogy maps — the moving steps to a treadmill's belt — and what it leaves out, that the steps fold flat at the top and bottom and you can still walk up it like ordinary stairs. Running `node main.ts` writes the two lines to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), using only the Node 22 standard library.
